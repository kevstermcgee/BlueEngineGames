# Dead Air

A flashlight-and-pistol survival horror game. Keep the Hollow Pine relay station broadcasting until dawn. Something out there answers back.

## Play

```
cargo run --release
```

WASD move, mouse look, Shift sneak, T flashlight, left mouse fire, E interact, J journal, F5/F9 save/load, F fullscreen, Esc menu.

Keep the generator fuelled and send five scheduled all-clear broadcasts before the 00:00-06:00 shift ends. The Caller is blind and hunts by sound: sneaking is quiet, running and gunfire are not. The flashlight and the pistol only stagger it for a few seconds, and ammo and battery are scarce on purpose. Five station-log pages scattered through the building tell the previous operator's story; read them any time in the Journal.

Every sound and the ambient track are generated by the engine's synth, so the game needs no asset files.

## Tests

The rules are a pure library (`src/lib.rs`), so every mechanic is tested without a window: `cargo test`. See `STATUS.md` for what is done and what is next.
