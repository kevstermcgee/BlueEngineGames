# Prop Hunt

Seven hiders disguise themselves as furniture while one seeker searches Hollow Pine.
Move with WASD, look with the mouse, pick a disguise with 1–0/scroll, and confirm
with E. The seeker holds Space to inspect. Esc opens the menu; F5/F9 save/load in
solo preview. Online rounds use the separate server described in docs/HOSTING.md.

The game includes a local solo preview and an eight-seat networked match. Empty
hider seats remain stationary disguises; they are not roaming bots. This is a
playtest: human network gameplay and tuning have not been verified.
